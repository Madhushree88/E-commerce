
# Return Policy by Product Category

This is a fictional policy for the Nykaa capstone project.

Apparel and Footwear products can be returned within 15 days of delivery if unused and with original tags.

Beauty products can be returned within 7 days of delivery only if unopened and sealed.

Electronics and Home products can be returned within 10 days of delivery if defective or damaged.

All return requests require a valid order ID and may be inspected before approval.
