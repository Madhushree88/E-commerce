
# Reverse Pickup Eligibility Policy

Reverse pickup is available for eligible return requests within supported delivery locations.

Customers must submit a return request within the applicable product-category return window.

The product must be packed securely with its original accessories, labels, and packaging where applicable.

Reverse pickup is scheduled after the return request is approved, subject to courier availability.

If reverse pickup is unavailable at the customer's location, the support team may offer an approved alternative return method.
