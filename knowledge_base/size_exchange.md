
# Size Exchange Policy

This is a fictional size-exchange policy for the Nykaa capstone project.

Customers can request a size exchange for eligible Apparel and Footwear products within 15 days of delivery.

The product must be unused, unwashed, and returned with its original tags and packaging.

Size exchanges are subject to availability of the requested replacement size.

Beauty, Electronics, and Home products are not eligible for size-based exchanges.

If the requested size is unavailable, the customer may request a return or refund according to the applicable category return policy.
